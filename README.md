# Counting Prototype

A small 3D catch-and-dodge game built in Unity, made as the Mission 6 counting prototype exercise from Unity's **Junior Programmer** learning pathway.

## Overview

Items fall from the sky into an Indian-themed room, and it's up to you to catch the good ones and dodge the bad ones before the timer runs out. Move the glass box left and right with the **arrow keys**. Your score is shown as a **Count** on screen, alongside the remaining **Time**.

## Items

| Item | Effect |
|------|--------|
| Chapati | +3 points |
| Kurkure | +3 points |
| Chai | +5 seconds |
| Dirty bottle | -3 points |

## Features

- Items spawn and fall from above
- Different items with different effects on score and time
- On-screen score counter and countdown timer
- Points and time rewards, plus a penalty item to avoid

## Built With

- Unity
- C#
